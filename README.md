# 🏏 IPL T20 Analytics Dashboard (Power BI)

An interactive Power BI dashboard designed to analyze IPL match statistics, team performances, toss decisions, and key player metrics.

## 🚀 Key Features & KPIs
- **Key Metrics:** Total Matches Played, Total Runs, Match Wickets, and Participating Teams.
- **Toss Analysis:** Visual breakdown of toss decisions (Bat vs Field).
- **Top Performers:** Dynamic insights on Top Player of the Match awards.
- **Interactive Filters:** Custom slicers for Teams and Seasons.

---

## 🛠️ Tools Used
- **Power BI Desktop** – Data Modeling, DAX, Visualizations
- **Data Source** – IPL Dataset (CSV/Excel)

---

## 📂 How to View
1. Download the `IPL T20 DASHBORED.pbix` file from this repository.
2. Open it in **Power BI Desktop**.
